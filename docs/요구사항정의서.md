## 2. 고객의 말 → 진짜 문제

| 고객의 말 | 진짜 문제 |
|---|---|
| "주문이 세 군데로 들어와서 합치는 게 일이에요" `N` / "종이가 쌓여서 빠뜨릴까 봐 걱정" `I5` | 주문이 흩어져 있어 **합치는 데 시간이 걸리고 빠뜨림** |
| "남은 수량… 지금은 감으로 해요" `N` / "따 봐야 알아요" `N` `I12` | 수량 기준이 없어 **너무 많이 받을 위험** (예약 포함) |
| "작년이랑 같은 걸로" `N` `I4` | 주문 기록을 **고객 기준으로 찾을 수 없음** |
| "3시 전만 그날… 금요일에 보내면 상해요" `N` / "입금 확인돼야 보내요" `N` | 오늘 보낼 주문을 **매번 머리로 골라냄** |
| "자료가 100쪽 넘어요… 어디 있는지 찾는 데 시간이 걸려요" `N` `I16` | 질문에 답할 때 **근거를 빨리 찾지 못함** |
| "배송 사고… 기록해 두고 싶어요" `N` | 사고 처리 이력이 남지 않음 |

> **한 줄 정의**: 세 경로 주문을 전화번호 기준으로 한곳에 모으고, 남은 수량과 발송 규칙을 시스템이 지켜서 정우 씨가 "누구에게 무엇을 언제 보낼지"를 머리로 맞추지 않게 한다.
