# 15. 농산물 직거래 농가 "햇살농원" 인터뷰 기록

> 고객 인터뷰실에서 복사한 원문. 질문 번호(I#)는 요구사항 정의서 3장과 같다.

[아버지] 안녕하세요. 저희 일 때문에 오셨죠? 인터뷰 내용은 보셨을 테니, 궁금한 거 편하게 물어보세요.

**I1** [나] 같은 고객인지 무엇으로 알아보세요? 전화번호인가요? 이름이 다르게 들어오면(예: "김순자" / "순자 어머님") 어떻게 하세요?

[정우 씨] 같은 분인지는 전화번호로 확인해요. 이름이 같아도 다른 분일 수 있어서 이름만으로는 판단하면 안 돼요. 이름이 다르게 적혀 있어도 전화번호가 같으면 같은 고객으로 보고 있어요.

**I2** [나] 가족이 대신 주문하는 경우(자녀가 부모님 번호로 주문 등)는 같은 고객으로 보세요, 따로 보세요?

[정우 씨] 그건 아직 정해 둔 기준이 없어요. 주문하신 분과 받는 분이 다를 수도 있어서, 저희도 확인하면서 처리하고 있어요. 어떻게 구분하면 좋을지 같이 생각해 보면 좋겠어요.

**I3** [나] 같은 사람이 카톡과 스마트스토어로 같은 걸 두 번 주문하면 중복으로 보고 하나를 취소하세요, 둘 다 보내세요?

[정우 씨] 같은 분이 두 군데로 주문하는 일이 있어서, 바로 하나를 취소하진 않아요. 주문 내용이 같으면 고객분께 확인한 뒤에 처리해요. 확인이 안 되면 지금은 주문마다 따로 챙기게 될 때도 있어요.

**I4** [나] 카톡 주문은 보통 어떤 모양으로 오나요? (예: "부사 선물용 5kg 3박스, 주소는 …") 정해진 양식이 있나요?

[정우 씨] 정해진 양식은 없어요. 품종, 선물용인지 가정용인지, 수량이랑 주소를 글로 보내시는 경우가 많고, 단골분들은 "작년이랑 같은 걸로"라고만 하시기도 해요. 명절에는 한 분이 받는 주소를 여러 곳 한꺼번에 보내기도 하고요.

**I5** [나] 전화 주문은 누가 받고, 지금은 어디에 적어 두세요? (종이 / 휴대폰 메모 / 엑셀)

[어머니] 전화는 제가 많이 받아요. 받아 적어 두었다가 정우한테 넘기면, 정우가 엑셀에 옮겨 적어요. 바쁠 때는 종이가 쌓여서 빠뜨릴까 봐 걱정돼요.

**I6** [나] 스마트스토어에서 내려받은 엑셀에는 어떤 칸이 있나요? (주문번호, 상품명, 옵션, 수령인, 주소, 연락처 …)

[정우 씨] 주문번호랑 상품명, 옵션, 주문하신 분과 받는 분 이름, 주소, 연락처 같은 내용이 들어 있어요. 실제 파일을 드리긴 어려우니, 저희 상황에 맞는 가상 예시로 만들어 주시면 돼요. 내려받은 내용을 보고 다른 주문들과 맞춰 엑셀에 정리하고 있어요.

**I7** [나] 주소가 다섯 군데인 주문은 박스 수를 주소마다 다르게 나누나요? 보내는 사람 이름은 주문자로 쓰나요?

[정우 씨] 주소마다 박스를 어떻게 나누는지는 주문하신 분이 말씀해 주신 대로 적고 있어요. 보내는 사람 이름을 어떻게 쓰는지도 따로 정해 둔 건 없어요. 명절 주문은 경우가 제각각이라, 주문 내용을 다시 확인할 때가 많습니다.

**I8** [나] 주소가 여러 개인 주문은 결제를 한 번에 하나요, 주소마다 따로 하나요?

[정우 씨] 보통은 주문하신 분이 한 번에 결제해요. 다만 주문 경로마다 방식이 달라서, 주소별로 따로 계산하는 기준까지는 정해 둔 게 없어요.

**I9** [나] 이 시스템을 누가 쓰나요? 정우 씨만인가요, 어머니·아버지도 보시나요?

[정우 씨] 제가 주문을 정리해서 가장 많이 쓸 것 같고요. 어머니는 포장할 때 주문 내용과 선물용 여부를 보셔야 해요. 아버지는 남은 수량이나 수확 상황을 확인하실 수 있으면 좋겠어요.

**I10** [나] 카톡이나 전화로 주문하실 때 주문하신 분 전화번호는 항상 받으세요? 카톡 주문에 번호가 없으면 어떻게 확인하세요?

[정우 씨] 전화 주문은 통화한 번호가 남으니 그걸 보고 적어요. 카톡은 채널로 들어온 주문이라도 번호가 바로 안 보일 때가 있어서, 필요한 경우 고객분께 물어봐야 해요. 번호를 못 확인하면 지난 주문과 같은 분인지 찾기가 어려워요.

**I11** [나] 판매하시는 상품을 알려 주세요. 사과·배·감자 각각 품종, 선물용·가정용, 박스 크기(kg)별로 가격이 어떻게 되나요?

[아버지] 사과는 홍로와 부사를 말씀드릴 수 있고, 홍로는 9월, 부사는 10월 말부터 나와요. 배와 감자의 품종, 등급별 상자 크기나 가격은 지금 정리된 기준을 말씀드리기 어렵네요. 선물용과 가정용은 구분해서 팔고 있습니다.

**I12** [나] 남은 수량은 박스로 세세요, kg으로 세세요? 팔 수 있는 양은 예상 수확량으로 미리 정하세요, 실제로 딴 만큼만 파세요?

[아버지] 품종과 등급별로 남은 양을 봐야 하는데, 지금은 딱 한 가지 단위로 통일해 세고 있진 않아요. 예상 수확량을 보고 주문을 받기 시작하지만, 실제로 따 봐야 정확한 양을 알 수 있어요. 그래서 너무 많이 받지 않도록 조심하고 있습니다.

**I13** [나] 부사처럼 아직 수확 전인 품종도 미리 주문을 받으세요? 받는다면 그 주문도 남은 수량에서 미리 빼야 하나요?

[아버지] 품종마다 판매를 시작하는 날이 있어서, 그 전에는 예약으로 주문을 받아요. 예약으로 받은 양도 나중에 보낼 수량을 생각해 함께 봐야 합니다. 실제 수확량은 따 봐야 확실해서 조심스럽게 받고 있어요.

**I14** [나] 금요일에 들어온 주문은 언제 보내세요? 목요일 오후 3시 이후에 들어온 주문은요? 감자도 똑같이 금요일에 안 보내세요?

[정우 씨] 금요일에는 택배를 보내지 않고, 그날 들어온 주문은 월요일 발송이라고 안내해요. 목요일 오후 3시가 지난 주문도 그날 택배에는 못 실으니 발송 일정을 따로 확인해야 해요. 감자까지 똑같이 적용하는지는 지금 정해 둔 기준이 없어요.

**I15** [나] 현금 입금은 누가, 언제, 어떻게 확인하세요? 입금자 이름이 주문하신 분과 다르면 어떻게 하세요? 입금이 며칠 안 되면 주문을 취소하세요?

[정우 씨] 현금 입금 주문은 입금이 확인돼야 보내고 있어요. 누가 확인하고 입금자 이름이 다를 때 어떻게 맞추는지, 며칠 뒤 취소하는지는 따로 정해 둔 기준이 없어요. 지금도 주문 내용과 입금 내용을 보면서 하나씩 확인합니다.

**I16** [나] 보관법·손질법 안내는 누가 쓰는 건가요? 고객이 직접 물어보는 화면인가요, 정우 씨가 답장할 때 참고하는 용도인가요?

[정우 씨] 지금은 고객분이 카톡이나 전화로 물어보시면 제가 찾아보고 답장하는 식이에요. 자료가 길고 어디에 있는지 찾는 데 시간이 걸려서, 답장할 때 참고하기 쉽게 되어 있으면 좋겠어요. 고객분이 직접 보는 방식까지는 아직 생각해 보지 않았어요.

**I17** [나] 농업기술센터 자료와 농원 쪽지 내용이 다르면 쪽지 내용만 답하면 되나요? 두 자료 어디에도 없는 질문은 어떻게 답할까요?

[어머니] 농원 쪽지와 센터 자료가 다르면 저희 쪽지를 따라야 해요. 상자에 넣는 안내가 저희 농산물 상태에는 더 맞을 때가 있거든요. 둘 다 없는 질문은 아직 어떻게 답할지 정해 두지 않았어요.

**I18** [나] "작년이랑 같은 걸로"라고 하시면 품종·등급·박스 크기·수량·받는 주소까지 전부 같게 보내면 되나요? 그 품종이 아직 안 나왔거나 떨어졌으면 어떻게 하세요?

[정우 씨] 지난 주문 기록을 보고 품종이나 등급, 수량을 확인한 뒤 주문을 다시 넣을 수 있으면 좋겠어요. 받는 주소까지 그대로인지도 확인은 해야 해요. 그 품종이 없을 때 어떻게 다른 상품으로 바꿀지는 아직 정해 둔 기준이 없어요.

**I19** [나] 배송 사고로 다시 보낼 때 남은 수량에서 빼나요? 재발송 말고 환불이나 다른 보상을 하는 경우도 있나요?

[정우 씨] 다시 보내 드릴 물량도 남은 수량을 보면서 챙겨야 할 것 같아요. 사고 접수는 받으신 날부터 2일 안에 사진과 함께 알려 주셔야 처리하고 있어요. 환불이나 다른 보상까지는 정해 둔 기준이 없어요.

**I20** [나] 고객은 돈 내고 주문하신 분의 전화번호로 잡고, 받는 분은 배송지로 따로 저장하려고 해요. 보내는 사람 이름은 기본으로 주문하신 분 이름을 쓰고 필요할 때 바꾸게 하려는데, 괜찮으세요?

[정우 씨] 그렇게 하면 주문하신 분과 받는 분이 다른 명절 주문도 구분하기 좋겠네요. 보내는 분 이름을 필요할 때 바꿀 수 있으면 주문 내용대로 맞추기 편할 것 같아요. 다만 전화번호를 못 받은 카톡 주문은 확인하는 과정이 필요해요.
